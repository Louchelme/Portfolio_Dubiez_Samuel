# Préambule
Ce projet est un projet universitaire pour le module 'R4.A.10 - complément web JavaScript' du BUT Informatique de l'IUT2 de Grenoble. Dans ce module, il nous est demandé de créé une interface pour une API de notre choix, en utilisant uniquement du JavaScript.  

# Description 
Notre choix s'est porté sur l'API de [jikan](https://jikan.moe/). L'application WEB vous permet de rechercher un anime, de l'ajouter à vos favoris, et entrer l'episode au quel vous êtes. Le detail des animes ajouté en favoris est stocké localement dans votre navigateur.

# Dépendance
La dépendance `php-cli` est nécéssaire au bon fonctionnement de l'application.  

# Mise en place
Après avoir effectuer le `git clone` du projet, il faut se rendre dans le repertoire "AnimList".  
Depuis ce repertoire, lancer un terminal et executer la commande `php -S localhost:8080`.  
L'application sera alors disponible sur le liens : [`http://localhost:8080/index.html`](http://localhost:8080/index.html)
